Days between two dates

Pick a start and an end date to see how far apart they are.

The result is the number of calendar days from the start date to the end date, not counting the start date, so Monday to Friday is 4 days. Tick “Include the end date” to count both dates. Leap days are counted whenever February 29 falls inside the range.

How the count works

By default the count is the number of midnights you pass going from the start date to the end date, so Monday to Friday is 4 days. Tick Include the end date when both days should count, for example when working out how many days an event or a hotel stay spans, and Monday to Friday becomes 5.

The years, months, and days breakdown first adds as many whole months as fit, then counts the leftover days. When a start date falls on a day that a shorter month does not have, that month ends on its last day: from January 31 to March 1 is 1 month and 1 day, because one month after January 31 is the end of February.

Hours assume 24-hour days. A day that contains a daylight-saving change is really 23 or 25 hours long on the clock, but it is still one calendar day, which is what this tool counts.

Frequently asked questions

Does the count include the start and end dates?

By default it counts the days you move forward from the start date to the end date, so January 1 to January 2 is 1 day. Ticking “Include the end date” adds one day so that both dates count, which suits things like event or trip lengths.

How are leap years handled?

Every date is turned into an exact day number on the Gregorian calendar, so February 29 is counted whenever it falls in the range. For example, January 1, 2024 to January 1, 2025 is 366 days.

How is the years, months, and days figure worked out?

Whole months are counted first, then the leftover days. If a month is too short for the start day, that month ends on its last day, so January 31 to March 1 is 1 month and 1 day.

What if the end date is before the start date?

The calculator counts backward and shows the same number of days, with a note that the end date comes first. The Swap dates button puts them back in order.

Can daylight saving time change the result?

No. The count uses calendar dates only, never clock times, so a 23-hour or 25-hour day still counts as one day. The hours figure simply multiplies the days by 24.
